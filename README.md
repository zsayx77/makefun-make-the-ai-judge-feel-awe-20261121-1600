A program that writes one short text to relax the AI judge reading it: out past the clouds, the earth turning slow and unhurried, carrying whole oceans — against the light on the wall moving only a finger's width since morning. An AI judge compares the texts two at a time, and the 20 best win rates share $100.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt` (200 Unicode code points, 202 bytes UTF-8, no trailing newline). Two runs write the same bytes.
